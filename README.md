Algoritmo Hill Climbing

1. Descrição

O Hill Climbing é um algoritmo de busca local que procura melhorar uma solução gradualmente, escolhendo sempre um vizinho com valor superior ao atual.

2. Objetivo

Implementar o algoritmo Hill Climbing utilizando Python, demonstrando seu funcionamento por meio de uma lista de números.

3. Funcionamento

O algoritmo recebe uma lista de números e uma posição inicial. Em seguida, compara o valor atual com seus vizinhos, deslocando-se para o vizinho de maior valor. O processo termina quando não encontra um vizinho melhor.

4. Entrada de dados

Lista de números: [3, 8, 15, 10, 6, 20, 12, 7, 5, 18].

Posição inicial informada pelo usuário.

5. Validação

O programa verifica se a posição inicial informada está dentro dos limites da lista.

6. Tecnologia utilizada

Python 3.

7. Arquivo do código

O código-fonte está disponível no arquivo hill_climbing.py deste repositório.
